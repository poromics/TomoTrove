# TomoTrove
A single HTML file for viewing your tomography image folders

## Usage
- Download the `TomoTrove.html` file.
- Open it. (Double-clicking it will open it in your default browser)
- Select the "Choose a library folder" button and browse to your tomograph library.

TomoTrove attempts to provide a user-friendly file-browsing interface with thumbnails and other helpful meta data shown.
