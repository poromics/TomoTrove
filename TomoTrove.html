LIBRARY CONTEXT

Notes & details

Welcome to TomoTrove

Choose a folder in desktop Chrome, Edge or Firefox. TomoTrove reads its subfolders locally; no files are uploaded and no internet connection is needed.

Browsing

Open a folder or image card. Numbered images with a shared naming pattern are grouped as a slice sequence. The sidebar tree expands with the arrows. Compact folders skips folders with one subfolder and no image files, even when they contain supporting files such as Info or .rcp. Top-level collection names remain in the compact labels. Switch it off to see every folder and access its supporting files or notes. Hover over a breadcrumb to see its full path. Turn off Group slices to inspect individual files. TIFF series can be selected in the display panel.

Viewing

Use the slice slider or ← → keys. Scroll to zoom, drag to pan, press F to fit and R to rotate. Contrast changes affect only the preview. Intensity histograms and robust percentiles are sampled for large slices.

Notes and RAW settings

Existing JSON sidecars are read automatically. In Chrome and Edge, saving asks for folder write permission and updates only metadata. Firefox supports browsing and reading existing notes; attempts to save explain that Chrome or Edge is required. No edits are written in browse mode. Refreshing in Firefox asks you to select the folder again. Empty folders are not included by its folder picker. RAW files without dimensions start with an editable cubic estimate from file size (uint8 unless a data type is already known). Changing the type or header offset recalculates the estimate until you edit a dimension. Confirm the Z, Y, X sizes, data type, and byte order. “Apply to preview” does not write a file.

Format support

TIFF/BigTIFF with uncompressed, LZW, Deflate, PackBits, JPEG, or Zstandard pixels; common raster images; numeric 2D/3D NPY; RAW; and complete cubic uint8 GBD grids. Some scientific TIFF layouts and codecs need additional support. Unrecognized files show an explanation. Very large individual slices are limited to keep the browser responsive.
